## 30 秒搞懂 CMI 和 CMIN2 的区别

CMI 全称 China Mobile International，是中国移动的国际子公司，AS 号 AS58453。判断一台机器走没走 CMI 很简单：路由测试里出现 **223.120.X.X 或 223.118.X.X** 的节点，基本就是它。这条线路的拥塞程度低于普通移动国际路由，对移动用户来说接近电信用户眼里的 CN2 GIA。

CMIN2 是另一回事，AS 号 **AS58807**，属于移动的独立专线，优先级高于普通 CMI，晚高峰的稳定性差距比较明显。验证方法是用 nextTrace 看回程落到移动节点时的 AS 号是不是 58807。

两者不能简单说谁“更好”，因为定位不同。CMI 便宜、覆盖广，香港机房用它做回程，物理距离摆在那里，体验已经超过绕日本、绕美国的洛杉矶普通线路；CMIN2 更贵更稳，通常出现在去程优化上。丽萨这套的做法是：去程电信走 CN2、联通走 AS9929、移动走 CMIN2，回程三网统一走 CMI。

这里有个行业坑值得说清楚。市面上标“香港 CMI”的便宜机器一抓一大把，但很多只做了回程 CMI，去程该绕还是绕，电信联通用户用起来延迟并不好看。三网去程都做优化，成本不低，这也是 ¥88/月 这个价位在同类里算偏低的原因——便宜的替代品通常省掉的正是这部分。

## FAQ

**CMI 和 CMIN2 哪个好？**
CMIN2（AS58807）是移动的独立专线，优先级高于普通 CMI（AS58453），晚高峰更稳。但这台机器的 CMIN2 用在去程，回程走 CMI，两者是配合关系不是二选一。真要验证，用 nextTrace 看回程落到移动节点的 AS 号。

**香港 CMI 的延迟到底多少？**
官方标注国内平均 50ms 左右。第三方实测里广州移动 14.81ms、广州电信 34.72ms、上海联通 43.54ms、北京联通 89.51ms。移动和华南最好，北方联通最差，差异比“平均值”这三个字大得多。

**¥88/月 这档是不是便宜货？**
在三网去程分别走 CN2、AS9929、CMIN2，回程统一 CMI，外加原生香港 IP 这个组合下，88 元月付在同类里算偏低。市面上更便宜的香港 CMI 通常只做回程优化，去程绕路，用起来是两回事。

**年付 ¥566 值不值？**
对比基础版月付 88×12=1056 元，省 490 元，接近对折；带宽还从 30Mbps 升到 50Mbps。代价是硬盘 20G 变 10G、月流量 1000GB 变 600GB。轻量用途值，需要存东西或流量吃紧的不值。

**电信、联通用户用这台机器体验如何？**
电信不错，去程走 CN2 精品线路，实测广州 34.72ms、上海 36.47ms。联通看地区，上海 43.54ms 尚可，广州 67.79ms、北京 89.51ms 就一般了。它不是只对移动好，但确实对移动最好。

**能不能装 Windows？**
可以，官方明确支持安装 Windows。注意装完先去面板确认随机分配的 SSH 端口。
